# 문서

DB Studio의 문서는 목적에 따라 셋으로 나뉜다.

- **쓰는 법** — 아래 "사용과 운영". 앱 안에도 같은 내용의 설명서가 있다(`/manual`).
  화면과 설명이 다르면 화면이 맞다.
- **왜 그렇게 만들었는가** — "설계 노트". 코드를 고치기 전에 읽는 문서다.
- **언제 무엇을 정했는가** — [PLAN.md](PLAN.md). 단계별(P0~P25) 결정과 근거의 시간 순 기록.

## 문서를 고칠 때

- 새 단계를 마쳤으면 [PLAN.md](PLAN.md)에 기록을 **더한다**(지우지 않는다).
- 동작이 바뀌었으면 [기능 목록](features.md)과 앱 안 설명서(`web/js/pages/manual.js`)를
  함께 고친다. 설명서는 바이너리에 임베드되므로 화면과 버전이 갈리지 않는다.
- 지원하지 않기로 정한 것은 [알려진 제약](limitations.md)에 이유와 함께 적는다.
  "안 된다"만 적힌 목록은 다음 사람이 같은 조사를 다시 하게 만든다.
